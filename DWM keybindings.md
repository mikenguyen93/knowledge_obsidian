in DWM
MODKEY = Alt
- MODKEY|w  : kill program
- MODKEY| r : open dmenu which show all program
- MODKEY | e: open file manager
- MODKEY| enter: Open terminal
- MODKEY | (1-9) : Change different tags/ workspace
- MODKEY | m : promote current windows to become masster
- MODKEY | t : return to tiling window
- MODKEY | s : run flameshot to screenshot
- MODKEY| Shift | (1-9): Move current programs to certain workspace/ tags
- MODKEY | Shift | q : Kill the dwm session or logout 
- MODKEY | Shift | space: Stop floating and return to tiling
- MODKEY | Shift | . : send focus windows to the next monitors
- MODKEY | Shift | , : send focus windows to the previous monitor. 
- MODKEY | Shift | f : make a widows fullscreen
in ST: 
- Zoom in/ out: Control | Shift | pgUp/PgDown
