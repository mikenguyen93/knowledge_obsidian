# Block Storage Options (BSO) #BSO:  
used for collecting planning user inputs, spreading and calculating data and facilitating the planning process on a daily basis

Allow to not only enter data at the leaf nodes but for target setting, you can enter data at any level in the dimensions

# Aggregate Storage Option (ASO) #ASO : 
also known as reporting cube 
Used for quick reporting and archiving historical data
ASO is database storage model that supports large scale, sparsely distributed data that is categorized into many potentially large dimensions
Selected data values are aggregated and stored
