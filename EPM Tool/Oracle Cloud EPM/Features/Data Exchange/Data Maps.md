What can Data Maps do:
	Allow to map and moe data between soure and target dimensions across:

			planning app: from planning to FCCS or tax reporting, between strategic modeling and planning
			freeform aps:
Data maps can be run directly from the data map page or can be triggered within a form using Smart Push

Key considerations: 
[[Smart Lists]] are not supported when pushing data from planning to [[EPCM]], [[FCCS]] or tax reporting
[[ASO cubes]] can be used as data sources
Rows containing only zeros, missing values or a combinations of both are automatically ignored during data pushes
